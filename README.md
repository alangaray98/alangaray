# Most Wanted Clothes

## Descripción

Sitio web desarrollado utilizando HTML, luego de la Clase-1 con el objetivo de practicar
la estructura básica de una página web, navegación mediante enlaces,
secciones, imágenes etc.

## Contenido

El sitio incluye:

- Página de inicio
- Catalogo
- Sobre Nosotros 
- Sucursales
- Contacto
